# Project 04 — Longitudinal Clinical Data Analysis

Portfolio project demonstrating repeated-measures data engineering, missing-data diagnostics, baseline-adjusted ANCOVA, and a random-intercept mixed model. The week-12 contrast is correctly parameterized by making week 12 the reference visit.

```bash
Rscript run_all.R
```

Open `docs/index.html` for the browser-ready report. Data are synthetic and contain no protected health information.
