# Clinical Trial Simulation Project

## Overview

This project simulates a randomized clinical trial evaluating continuous glucose monitoring (CGM) among adults with type 2 diabetes.

## Objectives

- Evaluate HbA1c reduction
- Demonstrate clinical trial workflow
- Develop reproducible statistical programming pipeline

## Methods

- ANCOVA
- Baseline balance assessment
- Data visualization

## Tools

- R
- Quarto
- Git
- GitHub

## Outputs

- Baseline characteristics table
- Statistical analysis results
- HbA1c visualization
