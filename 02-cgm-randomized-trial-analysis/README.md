# Project 02 — CGM Randomized Trial Analysis

## Question

Does continuous glucose monitoring (CGM) improve six-month HbA1c compared with standard care among adults with type 2 diabetes?

## Workflow

1. Simulate a two-arm randomized trial with baseline, three-month, and six-month HbA1c.
2. Summarize baseline comparability by treatment group.
3. Estimate the six-month treatment contrast with ANCOVA adjusted for baseline HbA1c, age, and sex.
4. Export a model-results table and a treatment-group visualization.
